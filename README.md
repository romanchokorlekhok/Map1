# আমার বাংলাদেশ — Interactive Travel Map

Unseen Bangladesh-inspired, original implementation for a 64-district travel map.

## Features
- 64 Bangladesh district selection
- Division-wise district list
- Bangla/English search
- Clickable district GeoJSON map
- Selected district counter and progress
- 6 color themes
- Optional name and photo
- PNG/JPG/PDF export
- Mobile responsive
- No backend required for the first version

## Run
Open `index.html` in a modern browser, or serve the folder with any static server.

For deployment, upload the folder to GitHub Pages, Netlify, Vercel, or any static hosting.

## Data
The map boundary is loaded from an open Bangladesh ADM2 district GeoJSON source. Check the source/license before commercial redistribution and keep attribution where required.
